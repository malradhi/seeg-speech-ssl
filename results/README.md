# Released results

| File | Contents |
|---|---|
| `stats/phase*_stats.json` | Outputs of the pre-specified statistical analyses (`analysis/`) used for every number, figure and table of the article; `*_n29.json` repeat every test without participant P30 |
| `analysis_outputs.zip` | The result bundles of every stage, which the analyses, figures and tables read (16 MB; 75 MB unpacked) |

Unpack the archive inside this folder:

```bash
unzip results/analysis_outputs.zip -d results/
```

which creates

```
phase1_bundle/   phase1_results.csv (13,230 runs), resolved configuration, data audit
phase2_bundle/   phase2_results.csv (33,845 runs), contamination/ (audit and positive controls per participant)
phase3_bundle/   phase3_results.csv (18,963 runs), runs/ (the stage's pretraining runs, with loss curves), eval/ (evaluation suite)
phase4_bundle/   phase4_results.csv (21,270 runs), eval4/, anatomy/ (contact locations and labels from the dataset), brainbert/ (feature-extraction summaries)
phase4b_bundle/  phase4b_results.csv (22,110 runs), eval4b/, anatomy/, brainbert/, brainbert_k64/
phase5_bundle/   ident5/   identification of the spoken segment, per participant
phase5w_bundle/  ident5w/  the same with word labels (accuracy over pairs of different words)
```

Each `phase*_results.csv` has one row per training run: participant, task, condition, label fraction, seed,
learning rate, labelled seconds, validation and test scores (overall r, within-speech r, MCD, chance levels),
training steps and the hashes of the code and configuration that produced it. The JSON files of the evaluation
and identification hold the per-participant results of every decoder, budget and seed.

The raw recordings are not included; they are openly available on OSF (project `ak3dp`, see the main README).
Model weights and test predictions are not included because of their size; they are regenerated by running the
study (`docs/RUNNING_THE_STUDY.md`).
